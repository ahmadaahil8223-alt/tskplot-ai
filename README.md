✨ TaskPlot AI

Turn problems into plans. Make progress one step at a time.

TaskPlot AI is a productivity and study-planning website designed to help people organise their tasks, solve problems, and prepare for exams.

🚀 Features

- 🤖 AI Assistant: Get guidance for organising problems into manageable steps.
- ✅ Task Manager: Add, track, complete, and organise tasks.
- 📚 Student Zone: Create personalised study schedules for exams.
- 📊 Progress Dashboard: Monitor tasks and study progress.
- ⭐ TaskPlot AI Plus: A planned premium experience with additional features.

📖 Getting Started

1. Open the website using the link above.
2. Explore the dashboard and task manager.
3. Add your tasks and organise your priorities.
4. Visit the Student Zone to create a study plan.
5. Try the assistant for basic planning guidance.

⚠️ Current Limitations

The current prototype uses built-in assistant responses rather than a live AI model. A live AI API integration may be added in a future version.

TaskPlot AI Plus is a planned premium feature and may not yet include payment or subscription functionality.

To make problem-solving, productivity, and exam preparation simpler and more organised for everyone.
